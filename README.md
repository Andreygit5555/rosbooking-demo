# Rosbooking — лендинг с переключаемой палитрой

Живая HTML-версия макета Rosbooking (Figma: `wuzkiD6cOwnfbxFeg2oZ24`).
Свёрстаны десктоп и мобильная версия, все секции, фото и тексты из макета.

## Главное — смена основной палитры

Кнопка с палитрой в правом нижнем углу открывает панель:

- готовые пресеты — Красный `#C32023`, Синий `#1A5AA8`, Графит `#111418`
  (ровно те три варианта, что есть в макете), плюс Изумруд, Океан, Слива, Янтарь, Роза;
- свой цвет через color-picker или HEX-поле;
- сброс к исходному красному;
- выбор сохраняется в `localStorage` и попадает в адрес (`?accent=1a5aa8`), так что ссылкой можно поделиться.

Цвет применяется ко всей странице: шапка, кнопки, иконки, цены, активные состояния, ссылки.
Для светлых оттенков автоматически подбирается контрастный текст (тёмный на акценте
и затемнённый акцент для текста на белом).

## Как запустить локально

```bash
python3 -m http.server 8787
# открыть http://127.0.0.1:8787/
```

## Структура

```
index.html      — разметка страницы
styles.css      — стили и адаптив (CSS-переменные --accent и производные)
app.js          — палитра, карусели, избранное, табы
assets/photos/  — изображения из макета
```

Технологии: чистый HTML/CSS/JS, без сборки и зависимостей.
Шрифт — Golos Text (Google Fonts).
